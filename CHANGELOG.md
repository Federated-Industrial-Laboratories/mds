# Changelog

## 0.1.0 development candidate

- Extract a reusable static documentation engine with explicit project identity,
  navigation, source adapters and hosting paths.
- Add independent palettes, colour modes, surface finishes and typography, with
  flat appearance and contrast fallbacks.
- Preserve configured project logos across themes, with optional dark variants
  and checked local branding assets.
- Provide local search, keyboard navigation, copy controls and print styling.
- Add pinned Git sources and portable snapshots with explicit publication edits.
- Provide build, preview, check, snapshot, package and starter commands.
- Ship portable adoption, documentation and release-maintenance skills.
- Include a neutral starter, component gallery and MDS's own manuals.

Configuration and source snapshot schemas begin at version 1. This candidate
does not imply public registry publication or a hosted service. Product source
versions remain independent of the MDS version.
