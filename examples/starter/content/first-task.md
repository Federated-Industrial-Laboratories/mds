# First task

Use this example to check instructions, code, a table and heading links.

## Build and read

1. Open a terminal in the project directory.
2. Build the documentation.
3. Start the local preview.

```sh
npx --no-install mds build
npx --no-install mds preview --port 4173
```

Open `http://127.0.0.1:4173/docs/`. Stop the preview with Ctrl+C when finished.

## Check the result

| Control | Expected result |
| --- | --- |
| Document menu | Open this page from the introduction. |
| Search | Search for `first task` and follow a result. |
| Surface finish | Select Flat in Appearance for simple surfaces; choose Typography separately. |
| Print | Print the article without the navigation shell. |
