# Example documentation

This starter demonstrates a small documentation site with local search, an
explicit navigation menu and reader-selected appearance.

## Read the guide

Follow the [first task](first-task.md) to try a complete example. Use the
appearance controls to switch between metal and flat surfaces. The palette,
colour mode and typography can be selected independently.

## Maintain the site

Edit these Markdown files and the navigation in `mds.config.json`. Rebuild the
site after a change:

```sh
npx --no-install mds build
npx --no-install mds check
```

This is a local preview. It is not a released product manual.
